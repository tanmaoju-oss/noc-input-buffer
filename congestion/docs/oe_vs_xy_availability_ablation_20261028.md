# OE 与 XY 延迟差距：资源回退对照

隔离实验保留原OE首选、合法候选及全部流量；仅在首选无可分配VC时尝试另一个合法方向。OFF六档精确复现原OE全部22个CSV字段，ON通过全部包和资源授权自检。

在0.04/0.06/0.08下，OE平均总延迟118.563/1774.974/2676.622降为74.981/1018.807/1797.902周期，降低36.758%/42.602%/32.829%；对应XY29.679/81.072/400.967，消除原OE—XY差距49.032%/44.641%/38.614%。因此该机制是重要因素，但这项单独改动未消除大部分差距，不能把整体退化主要简单归给提前锁定。

正式congestion/src和根src均未改；实验副本、代码/数据/命令和范围见[完整结果](../experiments/oe_va_fallback/docs/results_20261028.md)。单种子有限窗口，比例为该具体反事实干预的差值，不是可普遍相加的因果贡献率。
