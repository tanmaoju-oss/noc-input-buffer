# 输入块（`input_block`）模块代码分析

分析对象：`src/input_block_Xiugai2.sv`。本文按源码顺序说明当前生效逻辑。

## 模块功能与层级位置

`input_block` 汇集一个 router 的全部物理输入端口。当前 `PORT_NUM=5`，对应 `LOCAL/NORTH/SOUTH/WEST/EAST` 五个端口；每个端口内部又有 4 个 input buffer（VC）。

```text
router
└─ input_block
   ├─ input_port[LOCAL]
   ├─ input_port[NORTH]
   ├─ input_port[SOUTH]
   ├─ input_port[WEST]
   └─ input_port[EAST]
      └─ 每个 input_port 含 VC0–VC3 的 input_buffer
```

它不保存 flit、不做路由计算，也不实施仲裁；它的功能是将 5 个 input port 用三个接口统一接入 crossbar、VC allocator 和 switch allocator。

## 1. 模块接口（第 3–35 行）

```systemverilog
module input_block #(
    parameter PORT_NUM = 5,
    parameter BUFFER_SIZE = 8,
    parameter X_CURRENT = MESH_SIZE_X/2,
    parameter Y_CURRENT = MESH_SIZE_Y/2
)(
    input flit_t data_i [PORT_NUM-1:0],
    input valid_flit_i [PORT_NUM-1:0],
    input rst,
    input clk,
    input_block2crossbar.input_block crossbar_if,
    input_block2switch_allocator.input_block sa_if,
    input_block2vc_allocator.input_block va_if,
    output logic [VC_NUM-1:0] on_off_o [PORT_NUM-1:0],
    output logic [VC_NUM-1:0] vc_allocatable_o [PORT_NUM-1:0],
    output logic [VC_NUM-1:0] error_o [PORT_NUM-1:0]
);
```

`data_i[p]` 和 `valid_flit_i[p]` 是第 `p` 个物理输入端口的链路输入。其余三组接口按功能分工：

| 接口 | 方向 | 传递内容 |
| --- | --- | --- |
| `crossbar_if` | input block → crossbar | 每个输入端口被选中的 flit。 |
| `sa_if` | 双向 | input block 输出每个 VC 的交换请求；switch allocator 返回每个输入端口的获选 VC。 |
| `va_if` | 双向 | input block 输出每个 VC 的下游 VC 请求与目标端口；VC allocator 返回下游 VC 授权。 |

`on_off_o[p][v]`、`vc_allocatable_o[p][v]`、`error_o[p][v]` 分别从对应 input port/VC 汇集后输出给 router。

## 2. 本地状态和接口直连（第 37–46 行）

```systemverilog
logic [VC_NUM-1:0] is_full [PORT_NUM-1:0];
logic [VC_NUM-1:0] is_empty [PORT_NUM-1:0];
port_t [VC_NUM-1:0] out_port [PORT_NUM-1:0];

assign va_if.out_port = out_port;
assign sa_if.out_port = out_port;
```

`is_full/is_empty` 收集每个 input port 内各 VC 的 FIFO 状态，但当前 `input_block` 不在本文件中继续使用它们；它们没有接到模块外端口。

`out_port[p][v]` 是输入端口 `p` 的 VC `v` 当前队首 packet 的目标输出端口。两条 `assign` 把同一份路由结果同时交给：

- VC allocator：判断该 packet 要在哪个输出方向申请下游 VC；
- switch allocator：判断该 packet 要竞争本 router 的哪个输出端口。

## 3. 生成 5 个 input port 并完成接口连接（第 48–79 行）

```systemverilog
for(ip=0; ip<PORT_NUM; ip++)
begin: generate_input_ports
    input_port #(
        .BUFFER_SIZE(BUFFER_SIZE),
        .X_CURRENT(X_CURRENT),
        .Y_CURRENT(Y_CURRENT)
    ) input_port (
        .data_i(data_i[ip]),
        .valid_flit_i(valid_flit_i[ip]),
        .rst(rst), .clk(clk),
        .sa_sel_vc_i(sa_if.vc_sel[ip]),
        .va_new_vc_i(va_if.vc_new[ip]),
        .va_valid_i(va_if.vc_valid[ip]),
        .sa_valid_i(sa_if.valid_sel[ip]),
        .xb_flit_o(crossbar_if.flit[ip]),
        .is_on_off_o(on_off_o[ip]),
        .is_allocatable_vc_o(vc_allocatable_o[ip]),
        .va_request_o(va_if.vc_request[ip]),
        .sa_request_o(sa_if.switch_request[ip]),
        .sa_downstream_vc_o(sa_if.downstream_vc[ip]),
        .out_port_o(out_port[ip]),
        .is_full_o(is_full[ip]),
        .is_empty_o(is_empty[ip]),
        .error_o(error_o[ip])
    );
end
```

`generate` 在 elaboration 时实例化 5 个 input port。以 `ip=2` 为例，连接关系是：

```text
链路输入 data_i[2] → input_port[2]
input_port[2] 的 VC 请求 → va_if.vc_request[2]
VC allocator 返回授权 → va_if.vc_new[2] / va_if.vc_valid[2]
input_port[2] 的交换请求 → sa_if.switch_request[2]
switch allocator 选中 VC → sa_if.vc_sel[2] / sa_if.valid_sel[2]
被选 flit → crossbar_if.flit[2]
```

因此 input block 的主要价值是把每个端口局部的二维结构 `[端口][VC]` 统一放入 router 级接口：VC allocator 可看到所有 `5 × 4` 个 VC 请求；switch allocator 同样可在所有 `5 × 4` 个 VC 请求之间仲裁；crossbar 可接收每个输入端口最终选择出的一个 flit。
