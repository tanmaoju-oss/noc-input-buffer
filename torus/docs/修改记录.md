## 记录规则

从本文件建立之日起，每次修改按日期和当日序号追加独立条目，包括 RTL、TB、脚本和文档变更。开始时登记目的与范围，完成后补齐实际结果；后续修复另开条目并引用前项，保留原始失败证据。此前工作参见 [子项目进度](../README.md)，不追认为本次验证。

每条记录包括：

- 日期与编号、修改目的。
- 涉及文件、具体改动及行为影响。
- 验证命令、测试结果、日志或报告路径；未执行时说明原因。
- 遗留问题、验证边界与后续事项。
- Git 提交号、推送结果和 Windows 同步状态；尚未完成时如实标记，完成后补齐。

- **失败证据**：`vivado_sim_wsl/tb_torus_congestion_sim/run_hQuGIUz4/xsim.log` 在 2075 ns 报 `packet interleaving`。
